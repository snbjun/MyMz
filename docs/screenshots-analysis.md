# 参考资料页面分析

## 分析边界

- 本文只基于 `AGENTS.md` 和 `design_files/` 中的截图、HTML 导出文件进行需求分析。
- 参考资料仅用于理解功能、字段、页面流程、交互方式、打印格式、表格列和表单字段。
- 禁止在后续实现中直接复制原 HTML、CSS、Logo、图片、图标、静态资源、品牌名称或专有文案。
- 第一版按本地单机进销存系统重新设计，页面名称和字段名称保留业务含义，不保留参考软件品牌表达。

## 全局框架页

- 参考文件：`design_files/秒账.html`
- 页面名称：系统工作台/主框架
- 页面用途：承载左侧业务菜单、顶部工具栏、多标签页和当前登录用户信息。
- 主要按钮：刷新、消息、任务、更多、侧边菜单收起/展开、标签页关闭。
- 搜索条件：无独立业务搜索。
- 表格字段：无独立业务表格。
- 表单字段：无独立业务表单。
- 弹窗/抽屉/打印交互：消息通知、任务列表、公告/提示弹窗。
- 涉及的业务动作：切换模块、刷新当前页面、查看消息和导出任务。

## 客户列表

- 参考文件：`design_files/秒账-客户.png`、`design_files/秒账-客户.html`
- 页面名称：客户
- 页面用途：维护客户档案，查看客户合同金额、送货、预收款、未收款、已收款汇总。
- 主要按钮：搜索、新建客户、批量操作、行内编辑、删除/停用、收款/销售相关快捷操作。
- 搜索条件：客户名称、电话、产品、规格型号、客户分类等，截图中默认收起，仅显示搜索按钮。
- 表格字段：客户名称、电话、合同金额、已送货、预收款、未收款、已收款、操作。
- 表单字段：列表页无直接表单。
- 弹窗/抽屉/打印交互：批量操作下拉菜单，行内操作可进入编辑客户或相关业务单据。
- 涉及的业务动作：新增客户、编辑客户、删除/停用客户、查看客户交易汇总、按客户发起销售或收款。
