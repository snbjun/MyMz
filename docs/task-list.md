# 分阶段开发任务

## 1. 项目骨架

1. 创建前后端目录、Docker Compose、基础 README 和环境变量样例。
2. 初始化 FastAPI、SQLAlchemy、Alembic、Pytest 基础配置。
3. 初始化 Vue 3 + TypeScript + Vite + Element Plus 基础配置。
4. 建立后端分层目录：routes、services、repositories、schemas、models、tests。
5. 建立前端目录：api、views、components、router、stores、utils。
6. 增加统一响应、异常处理、Decimal JSON 序列化工具。
7. 增加基础 CI 脚本或本地测试命令文档。

## 2. 登录与用户

1. 创建用户、角色、权限、用户角色、角色权限表迁移。
2. 实现密码哈希、登录接口、当前用户接口、退出接口。
3. 实现用户列表、用户新增、编辑、禁用、重置密码接口。
4. 实现角色列表、角色新增、编辑、权限分配接口。
5. 实现前端登录页和登录状态管理。
6. 实现用户管理页面，包含搜索、分页、加载状态和表单校验。
7. 为登录、用户、角色接口补充 Pytest。

## 3. 客户

1. 创建客户分类、客户、客户地址表迁移。
2. 实现客户分类列表和新增接口。
3. 实现客户列表接口，包含分页、搜索和应收汇总字段。
4. 实现客户新增、详情、编辑、停用/软删除接口。
5. 实现客户列表页面，包含搜索、分页、加载状态。
6. 实现客户表单页面，包含分类、期初欠款、联系方式、地址。
7. 补充客户模块后端测试。

## 4. 供应商

1. 创建供应商分类、供应商、供应商地址表迁移。
2. 实现供应商分类列表和新增接口。
3. 实现供应商列表接口，包含分页、搜索和应付汇总字段。
4. 实现供应商新增、详情、编辑、停用/软删除接口。
5. 实现供应商列表页面，包含搜索、分页、加载状态。
6. 实现供应商表单页面，包含分类、期初欠款、联系方式、地址。
7. 补充供应商模块后端测试。

## 5. 产品

1. 创建产品、产品规格表迁移。
2. 实现产品列表接口，支持名称、条形码、规格搜索。
3. 实现产品新增接口，支持多规格、售价、进价、库存下限。
4. 实现产品详情、编辑、停用/软删除接口。
5. 实现产品列表页面，包含搜索、分页、加载状态。
6. 实现产品表单页面，包含多规格编辑和表单校验。
7. 补充产品模块后端测试。

## 6. 库存

1. 创建库存余额、库存流水表迁移。
2. 实现库存服务，封装入库、出库、调整、期初逻辑。
3. 产品新增时接入期初库存流水。
4. 实现库存列表接口，支持低库存筛选。
5. 实现库存流水查询接口。
6. 实现库存期初/盘点调整接口。
7. 实现库存列表页面和库存流水查看入口。
8. 补充库存事务、库存不足、盘点调整测试。

## 7. 销售单

1. 创建销售单、销售单明细表迁移。
2. 创建资金账户、资金流水表迁移中的销售收款相关能力。
3. 实现销售单号生成服务。
4. 实现销售单草稿保存、详情、编辑接口。
5. 实现销售单确认接口，事务内生成应收、库存出库、收款流水。
6. 实现销售单作废接口，事务内生成库存和资金反冲流水。
7. 实现销售单列表接口，支持状态、客户、日期、收款状态、送货状态查询。
8. 实现销售单列表页面。
9. 实现销售单新建/编辑页面，包含产品明细和收款明细。
10. 补充销售单草稿、确认、库存扣减、收款、作废测试。

## 8. 采购单

2. 扩展资金流水的采购付款能力。
3. 实现采购单号生成服务。
4. 实现采购单草稿保存、详情、编辑接口。
5. 实现采购单确认接口，事务内生成应付、库存入库、付款流水。
6. 实现采购单作废接口，事务内生成库存和资金反冲流水。
7. 实现采购单列表接口，支持状态、供应商、日期、付款状态、收货状态查询。
8. 实现采购单列表页面。
9. 实现采购单新建/编辑页面，包含产品明细和付款明细。
10. 补充采购单草稿、确认、库存增加、付款、作废测试。

## 9. 费用收入

1. 创建费用收入分类、费用收入记录表迁移。
2. 实现资金账户列表和维护接口。

## 10. 报表

1. 实现销售流水报表接口。
2. 实现采购流水报表接口。
3. 实现产品销售总览报表接口。
