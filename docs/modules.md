# 系统模块设计

## 总体范围

第一版实现本地单机进销存 BS 系统，技术栈为 Vue 3 + TypeScript + Vite + Element Plus、FastAPI + SQLAlchemy 2.x + Pydantic + Alembic、SQLite、Docker Compose、Pytest + Playwright。

后端按 route、service、repository 分层；销售、采购、库存、收付款必须使用数据库事务；金额字段使用 Decimal/Numeric；数量字段支持小数；业务数据优先软删除。

## 登录与用户

- 登录：账号密码登录、Token 会话、退出登录、当前用户信息。
- 用户管理：新增用户、编辑用户、禁用/启用用户、重置密码、用户列表搜索和分页。
- 角色权限：角色管理、角色权限分配、用户角色分配。
- 操作日志：登录成功、创建单据、修改单据、确认、作废、库存调整、资金流水等动作写入日志。

## 客户

- 客户列表：搜索、分页、客户交易汇总、批量操作。
- 客户档案：客户名称、分类、电话、备用电话、传真、邮箱、备注。
- 客户地址：一个客户可维护多个地址，可设置默认地址。
- 客户期初：期初欠款作为客户初始应收，纳入应收统计但不生成销售库存流水。
- 客户附件：合同、图片、资料文件等统一走附件模块。
- 客户往来：展示合同金额、已送货、预收款、未收款、已收款。

## 供应商

- 供应商列表：搜索、分页、供应商交易汇总、批量操作。
- 供应商档案：供应商名称、分类、电话、备用电话、传真、邮箱、备注。
- 供应商地址：一个供应商可维护多个地址，可设置默认地址。
- 供应商期初：期初欠款作为供应商初始应付，纳入应付统计但不生成采购库存流水。
- 供应商附件：合同、资质、报价单等统一走附件模块。
- 供应商往来：展示合同金额、已收货、预付款、未付款、已付款。

## 产品

- 产品列表：按名称、条形码、规格型号查询，支持分页和加载状态。
- 产品档案：产品名称、条形码、图片、标签、备注。
- 产品规格：一个产品可有多个规格型号，每个规格独立维护售价、进价、库存下限。
- 产品期初库存：新建产品时可录入期初库存，保存后生成库存期初流水。
- 产品附件：说明书、图片、资料等统一走附件模块。
- 产品状态：支持启用、停用、软删除。

## 库存

- 当前库存：按产品规格维护库存数量、库存下限、成本均价、更新时间。
- 库存流水：所有库存变化必须生成流水，来源包括期初、采购收货、销售送货、盘点、调整、作废反冲。
- 期初库存：用于系统初始化，生成入库方向流水。
- 库存盘点：按盘点数量和账面数量计算差异，差异生成调整流水。
- 库存预警：库存数量低于库存下限时可在列表标记。
- 库存导出：导出库存当前状态。

## 销售单

- 销售单列表：搜索、分页、草稿、未完成、批量导入导出、打印。
- 销售单表头：客户、销售日期、计划收款日期、送货日期、送货地址、税率、优惠金额、非产品费用、备注。
- 销售明细：产品、规格、数量、单价、金额、送货数量、备注。
- 收款明细：收款日期、收款金额、收款账户、备注、收款单号。
- 单据状态：草稿、已确认、已作废。
- 送货状态：未送货、部分送货、全部送货。
- 收款状态：未收款、部分收款、全部收款、超收款。
- 业务影响：确认后生成应收、收款资金流水、送货库存出库流水。

## 采购单

- 采购单列表：搜索、分页、草稿、未完成、批量导入导出、打印。
- 采购单表头：供应商、采购日期、计划付款日期、收货日期、收货地址、税率、优惠金额、非产品费用、备注。
- 采购明细：产品、规格、数量、单价、金额、收货数量、备注。
- 付款明细：付款日期、付款金额、付款账户、备注、付款单号。
- 单据状态：草稿、已确认、已作废。
- 收货状态：未收货、部分收货、全部收货。
- 付款状态：未付款、部分付款、全部付款、超付款。
- 业务影响：确认后生成应付、付款资金流水、收货库存入库流水。

## 收款付款

- 收款：来自销售单或客户预收款，增加资金账户余额，减少客户应收或形成预收。
- 付款：来自采购单或供应商预付款，减少资金账户余额，减少供应商应付或形成预付。
- 资金账户：现金、银行、其他账户，支持启用/停用。
- 资金流水：统一记录收款、付款、费用收入、作废反冲。
- 冲销：销售可使用客户预收款冲销，采购可使用供应商预付款冲销。

## 费用收入

- 费用收入列表：按单号、日期、类别、账户、制单人查询。
- 新增流水：选择收入或支出方向、类别、明细、账户、金额、备注。
- 业务影响：收入增加资金账户余额，费用减少资金账户余额。
- 作废规则：作废后生成反向资金流水，不物理删除原记录。
- 附件：票据、凭证等统一走附件模块。

## 报表

- 销售类：销售流水、产品销售总览、销售欠款汇总、销售业绩表、客户销售明细、客户对账单。
- 采购类：采购流水、采购付款汇总、供应商采购明细、供应商对账单。
- 库存类：送货提醒表、收货提醒表、库存当前表。
- 资金类：资金流水表、资金收入表、资金支出表、收支年报、净利润报表。
- 统计规则：默认只统计已确认且未作废单据；草稿不进入经营报表。
- 输出能力：查询、分页、导出、打印。

## 打印

- 打印对象：销售单、采购单、客户对账单、供应商对账单、基础报表。
- 打印配置：字段显示、图片显示、规格合并、纸张尺寸、页眉页脚模板、备注和签字栏。
- 打印快照：单据打印时按当前业务数据和打印配置生成，不复用参考资料版式代码。
- 打印入口：单据编辑页保存并打印、单据列表批量打印、报表页打印。

## 附件

- 通用附件：按业务对象类型和业务对象 ID 关联。
- 适用对象：客户、供应商、产品、销售单、采购单、费用收入。
- 文件字段：文件名、存储路径、大小、MIME 类型、上传人、上传时间。
- 安全限制：限制文件大小和扩展名，下载接口需鉴权。
- 删除规则：优先软删除附件记录，实际文件清理由备份策略或维护工具处理。

## 数据备份

- 手动备份：管理员可触发 SQLite 数据库备份。
- 恢复：恢复前必须生成当前数据备份，并提示风险。
- 备份记录：记录文件路径、大小、操作者、状态、错误信息。
- 导出：可导出备份文件。
- 约束：恢复属于高风险操作，必须限制管理员权限。

## 系统设置

- 基础设置：商户名称、联系人、电话、地址、默认税率、默认账户。
- 单号规则：销售单、采购单、收款单、付款单、费用收入单号前缀和日期序列。
- 分类设置：客户分类、供应商分类、费用收入类别。
- 打印设置：默认打印字段、模板、纸张。
- 权限设置：角色和权限属于用户模块，但入口可放在系统设置。
